# レスポンシブWebサイト（responsive-site）

このプロジェクトは、PC・タブレット・スマートフォンの各画面サイズに対応したレスポンシブWebデザインの練習用Webサイトです。

## 📱 プロジェクトの概要

画面の大きさに応じてレイアウトが柔軟に変化するカード型記事一覧ページを構築しています。
デベロッパーツール（検証ツール）のデバイスモードを用いて、各ブレークポイントでの適切な表示を確認・実装しています。

## ✨ 主な特徴・工夫点

- **モバイルファーストを意識したレスポンシブ対応**
  - メディアクエリ（`@media`）を活用し、デバイスに応じたレイアウトの切り替えを実施。
  - `calc()` 関数や Flexbox を用いた柔軟で崩れにくいグリッドレイアウトの構築。
- **デザイン・可読性の向上**
  - ブラウザごとのデフォルトスタイルをリセット（`reset.css` 適用）。
  - インターネット経由で読み込む **Webフォント** を導入し、どの環境でも統一された美しいタイポグラフィを実現。

## 📐 レイアウト仕様（ブレークポイント）

| デバイス | 画面幅 | レイアウト仕様 |
| :--- | :--- | :--- |
| **PC** | 1025px 以上 | 記事カード **3列** 表示 |
| **タブレット** | 600px 〜 1024px | 記事カード **2列** 表示・文字サイズ最適化 |
| **スマートフォン** | 599px 以下 | 記事カード **1列** 表示・文字サイズ最適化 |

## 🛠 使用技術（Tech Stack）

- **HTML5** (構造化)
- **CSS3** (Flexbox, `calc()`, メディアクエリ, Webフォント, reset.css)
- **Git / GitHub / GitHub Desktop** (バージョン管理・公開)
